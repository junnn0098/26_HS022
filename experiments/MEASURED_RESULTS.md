# 실측 데이터 학습 결과

팀이 직접 수집한 [CSI 데이터셋](../dataset/README.md)으로 v1 1D-CNN 낙상 감지 모델을 학습·평가한 결과입니다. 1·2차 수집(07-08·07-09) 1,019개 윈도우와 전체 2,217개 윈도우에서 각각 5회 반복했습니다.

<p align="center"><img src="results/figures/v1_results.png" alt="v1 1D-CNN 낙상 감지 성능" width="760"></p>

## 데이터

| 항목 | 내용 |
|---|---|
| 윈도우 | [`dataset/metadata/windows.csv`](../dataset/metadata/windows.csv)의 500패킷 윈도우(중앙값 5.0초) |
| 1·2차 수집 | 07-08·07-09, 1,019개(낙상 302개), 동작 11종 |
| 전체 | 07-08–07-28 5회 수집, 2,217개(낙상 969개), 동작 15종 |
| 라벨 | 낙상(`fall`) = 1, 일상 동작·혼동 동작 = 0 ([동작 라벨](../dataset/README.md#동작-라벨)) |
| 입력 형식 | 윈도우당 134채널 × 500패킷 ([134채널 구성](../dataset/README.md#134채널-구성)) |

## 모델과 학습

| 항목 | 내용 |
|---|---|
| 모델 | `CSI1DCNN`([model.py](../edge_ai/hanium_fall_v1/model.py)): 1D 합성곱 3단(32·64·128 필터) + 전역 평균 풀링 + 선형 분류층, 낙상/비낙상 2클래스 |
| 전처리 | 윈도우별 z-score(134 × 500 값 전체의 평균·표준편차) |
| 학습 | 가중 교차 엔트로피, Adam(학습률 1e-3, weight decay 1e-4) + cosine, 25 epoch, 배치 32 ([train.py](../edge_ai/hanium_fall_v1/train.py)) |
| 환경 | CPU, Python 3.13, PyTorch 2.14, 2스레드, 시드 고정·결정적 연산 설정 |

## 평가 방법

| 항목 | 내용 |
|---|---|
| 분할 | 라벨별 층화 윈도우 무작위 80/20(`--protocol random`) |
| 반복 | 시드 0–4, 5회. 지표는 평균 ± 표준편차, TP·FP·TN·FN은 5회 합계 |
| 판정 | 낙상 확률(softmax) ≥ 0.5이면 낙상. 임계값과 무관한 순위 지표로 AUROC를 함께 계산 |

## 결과

| 데이터 | 시험 윈도우(5회 합계) | 낙상 재현율 | 정밀도 | F1 | AUROC | TP | FP | TN | FN |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1·2차 수집 (07-08·07-09) 1,019개 | 1,015 | 0.997 ± 0.007 | 0.990 ± 0.008 | 0.993 ± 0.006 | 1.000 | 299 | 3 | 712 | 1 |
| 전체 (07-08–07-28) 2,217개 | 2,210 | 0.922 ± 0.014 | 0.953 ± 0.021 | 0.937 ± 0.016 | 0.986 ± 0.004 | 894 | 44 | 1,196 | 76 |

- 1·2차 수집 1,019개에서는 5회 시험 세트 합계 낙상 300개(회당 60개) 중 299개를 찾았고, 오경보는 3건입니다.
- 전체 2,217개에서는 5회 시험 세트 합계 낙상 970개(회당 약 194개) 중 894개를 찾았고, 오경보는 44건입니다. 특이도 0.965 ± 0.016, 정확도 0.946 ± 0.014입니다.
- 두 실험 모두 **비틀거리기(넘어지지 않음)를 낙상으로 판정한 경우는 0건**입니다.

### 동작별 오탐

낙상이 아닌 시험 윈도우 중 낙상 확률이 0.5 이상인 윈도우 수입니다(5회 합계). `-`는 해당 데이터에 없는 동작입니다.

| 구분 | 동작 | 1·2차 수집 1,019개 오탐 / 시험 | 전체 2,217개 오탐 / 시험 |
|---|---|---:|---:|
| 혼동 동작 | 걸어다니며 물건 줍기 | 2 / 55 | 4 / 55 |
| 혼동 동작 | 누웠다 일어나기 | 1 / 55 | 2 / 90 |
| 혼동 동작 | 비틀거리기(넘어지지 않음) | 0 / 55 | 0 / 55 |
| 혼동 동작 | 앉았다가 눕기(반복) | 0 / 60 | 0 / 60 |
| 혼동 동작 | 쪼그려 앉았다 일어나기 | - | 2 / 35 |
| 혼동 동작 | 허리 숙여 물건 줍기 | 0 / 50 | 0 / 50 |
| 일상 동작 | 가만히 서 있기 | 0 / 65 | 0 / 65 |
| 일상 동작 | 가만히 앉아 있기 | 0 / 65 | 3 / 160 |
| 일상 동작 | 걷기 | 0 / 60 | 11 / 145 |
| 일상 동작 | 누워 있기 | - | 1 / 65 |
| 일상 동작 | 앉기 | - | 0 / 45 |
| 일상 동작 | 앉았다 일어나기 | 0 / 185 | 11 / 320 |
| 일상 동작 | 의자에서 움직이기 | - | 10 / 30 |
| 일상 동작 | 팔 흔들기 | 0 / 65 | 0 / 65 |
| 합계 | | 3 / 715 | 44 / 1,240 |

전체 실험의 오경보 44건 중 32건은 걷기·앉았다 일어나기·의자에서 움직이기에서 나왔습니다. 혼동 동작 6종의 오탐은 합계 8건입니다.

## 재현

PyTorch와 데이터셋 파일이 필요합니다. 저장소 루트에서 실행합니다.

```bash
python -m pip install -r edge_ai/requirements.txt torch -r experiments/requirements.txt
python dataset/tools/download.py                  # 학습 윈도우 NPZ 4개 (189MB) -> dataset/data/
python experiments/run_v1_experiments.py          # b1_random, random_all (CPU 약 7분)
python experiments/make_results_table.py          # 위 표 두 개
python experiments/plot_figures.py                # 그림
```

공개한 결과는 `--threads 2`(기본값)로 만들었으며, 스레드 수가 다르면 소수 셋째 자리에서 차이가 날 수 있습니다.

| 결과 폴더 | 데이터 |
|---|---|
| [`results/v1/b1_random/`](results/v1/b1_random) | 1·2차 수집 1,019개 |
| [`results/v1/random_all/`](results/v1/random_all) | 전체 2,217개 |

폴더마다 `summary.json`(평균·표준편차·혼동 행렬 합계·실행 환경), `runs.json`(시드별 지표·동작별 낙상 판정 비율·학습 손실), `predictions.csv`(시험 윈도우별 낙상 확률)가 있고, 실행 로그는 [`results/v1/logs/`](results/v1/logs)에 있습니다.
