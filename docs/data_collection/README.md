# 실환경 CSI 데이터 수집 기록

공개 데이터셋만으로는 실제 설치 공간에서 성능이 나오지 않는 문제(도메인 갭)를 해결하기 위해, 직접 설치한 센서 환경에서 CSI를 녹화하고 웹캠 관절 좌표(keypoint)를 동시에 기록해 자동 라벨링용 데이터를 쌓았습니다. 이 폴더는 그 녹화 세션의 목록입니다.

## 수집 방식

```text
ESP32-S3 수신 노드 ──CSI──▶ RuView 녹화       → data/recordings/csi-<epoch>.csi.jsonl
웹캠 ──────────────영상──▶ 관절 좌표 추출    → data/ground-truth/keypoints_<YYYYMMDD_HHMMSS>.jsonl
                                   │
                    두 파일의 시작 시각으로 시간 동기화
                                   ▼
            keypoint로 판별한 행동을 같은 시간대의 CSI 구간에 라벨로 부여
```

- CSI 파일명의 숫자는 녹화 시작 시각(Unix epoch)이고, 키포인트 파일명은 녹화 시작 시각(KST)입니다.
- 36개 녹화 중 35개가 CSI와 키포인트 파일 쌍을 이루며, 두 파일의 시작 시각 차이는 모두 5초 이내입니다. 1차 첫 녹화(걷기)만 키포인트 없이 CSI만 기록했습니다.
- 원본 CSI·키포인트 파일은 용량 문제로 저장소에 포함하지 않았습니다.
- 참여자는 실명 대신 익명 ID(S1, S2)로 표기했습니다. 참여자를 기록하지 않은 세션은 `-`입니다.

## 세션 요약

| 차수 | 날짜 | 녹화 수 | 낙상 | 혼동 동작 | 일상 동작 | 주요 동작 |
|:---:|:---:|:---:|:---:|:---:|:---:|---|
| 1차 | 2026-07-08 | 8 | 2 | 1 | 5 | 걷기, 앉았다 일어나기, 팔 흔들기, 서 있기, 앉아있기, 앉았다가 눕기 |
| 2차 | 2026-07-09 | 9 | 3 | 4 | 2 | 누워있다 일어나기, 물건 줍기(2종), 비틀거리기, 의자에 앉았다 일어나기 |
| 3차 | 2026-07-24 | 13 | 6 | 2 | 5 | 참여자 2명, 쪼그려 앉았다 일어나기, 누웠다 일어나기, 누워있기 |
| 4차 | 2026-07-28 | 6 | 3 | 0 | 3 | 앉았다 일어나기, 앉아있기, 걷기 |
| **합계** | | **36** | **14** | **7** | **15** | |

- **낙상** : 실제로 넘어지는 동작
- **혼동 동작** : 몸이 바닥 쪽으로 크게 내려가거나 균형을 잃는 등 낙상과 CSI 패턴이 비슷해 오탐을 일으키기 쉬운 동작 (비틀거리기, 물건 줍기, 쪼그려 앉기, 눕기·누웠다 일어나기)
- **일상 동작** : 걷기, 서 있기, 앉기·앉아있기, 누워있기 등

2차 수집부터 혼동 동작을 의도적으로 늘려, 모델이 "바닥으로 내려가는 모든 동작"을 낙상으로 판단하지 않도록 학습 데이터를 구성했습니다.

## 전체 목록

[`collection_log.csv`](collection_log.csv)에 녹화별 상세 정보가 있습니다.

| 컬럼 | 설명 |
|---|---|
| `session` | 수집 차수 (1~4) |
| `date`, `csi_start_kst` | 녹화 날짜와 CSI 녹화 시작 시각 (KST) |
| `csi_file` | RuView CSI 녹화 파일명 |
| `keypoints_file` | 같은 시간대의 웹캠 관절 좌표 파일명 |
| `label_ko` | 수집 당시 기록한 동작 |
| `label_canonical` | `edge_ai/hanium_fall_v2/labels.py`의 행동 라벨 중 대응하는 것 |
| `category` | 낙상 / 혼동 동작 / 일상 |
| `subject` | 익명 참여자 ID |

## 평가 데이터와의 관계

이 CSV의 단위는 녹화 세션입니다. 개발보고서의 1,019개 평가 클립이나 모델 입력 창 개수와 같지 않습니다. 현재 저장소에는 세션에서 클립을 생성한 대응표와 보고서 평가 분할이 없어 두 수치를 직접 연결하지 않습니다.

파일 시작 시각이 5초 이내라는 사실만으로 프레임 단위 라벨 정렬의 정확성이 검증되는 것은 아닙니다. 평가 자료를 공개할 때는 원본 시각 오프셋, 클립 구간, 라벨 변환 규칙, 피험자·환경별 분할을 함께 기록합니다. 보고서의 11종 동작과 현재 모델의 10종 라벨 대응도 확인해야 합니다.
