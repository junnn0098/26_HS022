# 실환경 평가 절차

이 문서는 앞으로 실제 센서·가중치·단말로 수행할 평가 절차입니다. [완료한 소프트웨어 실험](../../experiments/RESULTS.md)과 구분하며, 아래 항목에 대한 새 측정 결과를 만들어 기입하지 않았습니다.

## 평가를 구분하는 기준

| 단계 | 평가 대상 | 필요한 증거 | 이번 자료 |
|---|---|---|---|
| 입력·후처리 | 파서, 특징 배열, 상태기계 | 입력 fixture·단계별 출력 | 단위 테스트 및 합성 실험 |
| 모델 | 고정 시험 세트의 행동·인원 분류 | 가중치 해시·manifest·정답·예측 | 공개 가중치·시험 세트 미포함 |
| 이벤트 | 연속 시계열의 낙상 경보 | 낙상 시작 시각·경보 시각·장기 정상 기록 | 별도 실환경 평가 필요 |
| 호흡 | 기준 장치 대비 수치와 측정 가능 비율 | 같은 시각의 기준 호흡값·CSI·품질 상태 | 현재 합성 주파수 복원만 수행 |
| 알림 | 센서 입력부터 보호자 단말까지 | 서버 로그·푸시 응답·실제 수신 시각 | 현재 로컬 HTTP만 확인 |

## 실행 전에 고정할 항목

코드 커밋, 모델 SHA-256, 설정 파일, 펌웨어 커밋·빌드 옵션, 노드 ID·배치, 채널·대역폭, 공간 ID, 익명 참여자 ID, 기준 시계와 정렬 방법을 기록합니다. 정답 라벨을 확인한 뒤 시험 성적이 좋아지도록 임계값을 바꾸지 않습니다. 조정은 검증 세트에서 하고, 변경 시 시험 결과의 모델·설정 버전을 새로 구분합니다.

## 모델과 낙상 이벤트

- 동일 참여자·녹화·겹치는 창이 분할을 가로지르는지 검사합니다. 참여자 정보가 없는 기록은 분할 근거를 먼저 보완해야 합니다.
- 클래스별 support, precision, recall, F1과 혼동행렬을 저장합니다. 정확도 하나만 보고 낙상 미탐을 숨기지 않습니다.
- 창 단위 분류와 최종 경보 이벤트는 별도로 평가합니다. 하나의 낙상에서 반복된 경보를 어떻게 묶을지, 어느 시간 범위까지 탐지로 셀지 평가 전에 정합니다.
- 비틀거림, 물건 줍기, 앉기, 눕기, 일어서기를 구분해 오경보를 기록합니다. 정상 관찰 시간과 오경보 건수로 시간당·일당 비율을 계산합니다.
- 기본 `acceptance_check.py`의 낙상 recall 0.95는 코드의 목표값입니다. 합성 시나리오 성공으로 통과를 대신하지 않습니다.

## 신호 손실·복구

노드 4→3→2→1→0개, 일시적인 패킷 누락, 중앙 구간의 연속 누락, 추론 프로세스 중단, 연결 클라이언트 중단, 서버 재시작을 각각 기록합니다. 단순히 배열이 생성되는지 외에 `마지막 실제 수신 시각`, `판단 가능 여부`, `확정 경보 유지 여부`, `복구 시각`을 함께 확인합니다.

현재 실험에서는 패킷 개수가 같을 때 긴 공백이 품질 점수에 반영되지 않는 경우가 발견됐습니다. 이 실험의 노드 마스크 통과를 통신 단절 대응 완료로 해석하지 않습니다.

## 호흡 비교

기준 장치의 측정 구간과 CSI 추정 구간을 정렬하고, 반환된 값의 MAE·중앙 절대 오차·상위 오차뿐 아니라 전체 관찰 구간 대비 값이 제공된 비율도 보고합니다. 움직임·다인 환경·신호 부족으로 값을 내지 않은 구간을 조용히 제외하지 않습니다. 현재 입력은 고정 사인파이므로 사람의 호흡 정확도로 일반화할 수 없습니다.

## 단말 알림과 전체 지연

기준 시각을 동기화하고 `동작 시작 → 모델 출력 → 경보 확정 → 서버 수신 → FCM 응답 → 단말 수신·화면 표시`를 분리해 남깁니다. FCM API 성공만으로 실제 보호자가 알림을 받았다고 판단하지 않습니다. 전경·백그라운드·종료 상태, 네트워크 단절 후 복구를 각각 확인합니다.

전화 대응은 테스트 연락처로 전화 앱이 열리는 범위에서 확인합니다. 실제 119 발신을 실험 절차에 포함하지 않습니다.

## 공개할 결과 묶음

입력 파일 해시, 데이터 분할 manifest, 가중치·설정 식별값, 원시 예측·정답 CSV, 지표 JSON, 그래프 생성 스크립트, 환경 정보와 실패 사례를 함께 묶습니다. 실제 개인정보가 포함된 영상·연락처·주소·서비스 계정 키는 평가 산출물에 넣지 않습니다. 논문과 비교할 때는 장비·인원·장소·분할·지표 정의의 차이를 명시합니다.
