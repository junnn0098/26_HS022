# 발표 당일 빠른 실행 순서 - 172.20.10.2

이 패키지는 친구 노트북 Wi-Fi IPv4가 아래 주소일 때 기준입니다.

```text
172.20.10.2
```

`192.168.56.1`은 가상 어댑터 주소라 사용하지 않습니다.

## 1. 서버 실행

PowerShell 또는 파일 탐색기에서 아래 파일을 실행합니다.

```text
run_friend_1_server.cmd
```

서버 창은 발표가 끝날 때까지 닫지 않습니다.

관리자 페이지:

```text
http://127.0.0.1:8000/admin
```

## 2. 실제폰 release APK 만들기

실제폰에 설치할 APK가 필요하면 아래 파일을 실행합니다.

```text
run_friend_4_build_release_apk_real_phone.cmd
```

생성되는 APK:

```text
release_apk/hanium_guardian_realphone_172.20.10.2.apk
```

이 APK에는 서버 주소 `http://172.20.10.2:8000`이 들어갑니다.

## 3. 에뮬레이터로 바로 실행할 때

에뮬레이터를 사용하면 아래 파일을 실행합니다.

```text
run_friend_2_app_emulator.cmd
```

에뮬레이터는 서버 주소로 `http://10.0.2.2:8000`을 사용합니다. 정상입니다.

## 4. 실제폰을 Flutter run으로 실행할 때

실제폰을 USB로 연결해 Flutter run으로 띄울 경우 아래 파일을 실행합니다.

```text
run_friend_2_app_real_phone.cmd
```

실제폰은 서버 주소로 `http://172.20.10.2:8000`을 사용합니다.

## 5. 연결 확인

서버 연결이 의심되면 아래 파일을 실행합니다.

```text
run_friend_3_check_server.cmd
```

## 6. 시연 순서

1. 서버 실행
2. 관리자 페이지 열림 확인
3. 앱 실행 또는 APK 설치
4. 앱에서 `집 안` 화면 확인
5. 관리자 페이지에서 `정상`, `현관 접근`, `장시간 무반응`, `낙상 의심` 순서로 실행
6. 앱에서 미니어처 위치, 이동 잔상, 알림, 위험 상세 화면이 바뀌는지 확인

## 7. 안 될 때

- 친구 PC IP가 여전히 `172.20.10.2`인지 `ipconfig`로 확인합니다.
- 실제폰과 노트북이 같은 핫스팟/Wi-Fi에 연결되어 있어야 합니다.
- Windows 방화벽에서 Node.js 또는 포트 8000을 허용해야 합니다.
- 발표 안정성은 실제폰보다 에뮬레이터가 더 높습니다.
