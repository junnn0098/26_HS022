# 한이음 앱 시연 스크립트

발표 중 시연이 꼬이지 않도록 정해진 순서대로 진행하기 위한 체크리스트입니다.

## 1. 실행 준비

서버 실행:

```powershell
cd C:\Users\juhwan\Documents\Codex\2026-06-23\new-chat\Hanium_fastApi
.\run_mock_server_node.cmd
```

앱 실행:

```powershell
cd C:\Users\juhwan\Documents\Codex\2026-06-23\new-chat\Hanium_app
.\run_emulator_local.cmd
```

`run_emulator_local.cmd`는 발표 모드(`DEMO_MODE=true`)로 실행됩니다.  
실제 보호자 화면처럼 시연 버튼이 없는 상태를 확인하려면 아래 명령을 사용합니다.

```powershell
.\run_emulator_user_mode.cmd
```

관리자 페이지 열기:

```powershell
start http://127.0.0.1:8000/admin
```

## 2. 관리자 페이지 발표 리모컨

관리자 페이지 오른쪽의 `발표 리모컨` 영역을 사용합니다.

추천 순서:

1. `1. 시연 시작`
2. `2. 평소 상태`
3. `3. 현관 접근`
4. `4. 무반응`
5. `5. 낙상 의심`
6. `6. 안전 확인`

빠르게 전체 흐름을 보여주고 싶으면 `자동 시연`을 누릅니다.

발표 멘트가 필요하면 `멘트 복사`를 누른 뒤 발표 자료나 메모장에 붙여넣을 수 있습니다.

## 3. 시연 전 초기화

관리자 페이지에서 `1. 시연 시작` 또는 `시연 상태 초기화` 버튼을 누릅니다.

정상 기준:

- 관리자 페이지 상태: 거실 / 정상
- 앱 상태: 이상 징후 없음
- 앱 안심 카드: 안심 시스템 정상 작동 중
- 홈 다음 행동 안내: 집 안 상태 보기로 이동 가능

## 4. 정상 상태 설명

앱 홈/집 안 화면에서 설명합니다.

- 카메라 없이 WiFi CSI 기반 움직임을 추정
- 보호자가 집 안 상태를 도면으로 확인
- 위치는 정확한 감시가 아니라 보호자용 안전 신호로 제공

## 5. 현관 접근 시나리오

관리자 페이지에서 `3. 현관 접근` 또는 `현관` 버튼을 누릅니다.

확인할 것:

- 앱 도면의 사람이 현관 쪽으로 이동
- 상태가 `현관 접근`으로 변경
- 알림 목록에 현관 접근 기록 생성
- 홈 다음 행동 안내가 위치 확인/연락 흐름을 제안

설명 포인트:

- 배회/외출 가능성을 보호자에게 빠르게 알려줄 수 있음
- 카메라 없이 위험 구역 접근을 감지한다는 점을 강조

## 6. 낙상 의심 시나리오

관리자 페이지에서 `5. 낙상 의심` 또는 `낙상 의심 발생` 버튼을 누릅니다.

확인할 것:

- 앱 도면의 사람이 거실 쪽으로 이동
- 빨간 위험 상태 표시
- 홈 다음 행동 안내가 긴급 화면 열기를 제안
- 알림 화면에서 위험 알림 확인
- 위험 상세에서 `왜 알림이 떴나요?` 설명 확인
- 긴급 화면에서 현재 위치/최근 확인 시각/119 신고 정보 확인

설명 포인트:

- 보호자가 바로 전화/문자/119 신고 정보를 확인
- 주소, 출입 안내, 의료 참고사항을 한 화면에 제공
- 앱은 좌표나 서버 상태가 아니라 보호자가 이해할 수 있는 “상황과 다음 행동”으로 보여줌

## 7. 장시간 무반응 시나리오

관리자 페이지에서 `4. 무반응` 또는 `장시간 무반응` 버튼을 누릅니다.

확인할 것:

- 앱 상태가 주의 상태로 변경
- 장시간 움직임이 적다는 알림 생성

설명 포인트:

- 낙상처럼 명확한 이벤트뿐 아니라 생활 패턴 이상도 감지 가능

## 8. 알림 상세 화면

앱 알림 목록에서 알림을 누릅니다.

확인할 것:

- 감지 위치/시각
- 현재 집 안 상태
- 감지 확실성
- 왜 알림이 떴는지
- 보호자가 바로 해야 할 일
- 도면
- 알림 내용 복사

## 9. 마무리

관리자 페이지에서 `6. 안전 확인`, `알림 확인 완료`, 또는 `시연 상태 초기화`를 누릅니다.

마지막 설명:

- 현재는 시연용 관리자 페이지와 mock 서버
- 실제 센서는 `/sensor/update` API로 연결 준비 완료
- 향후 CSI 정확도 개선, 다중 사용자 구분, 실제 푸시 알림을 확장 예정

## 10. 문제가 생겼을 때

서버 확인:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

최신 위치 확인:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/location/latest
```

앱이 안 따라올 때:

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/sensor/update -ContentType 'application/json' -Body '{"x":0.76,"y":0.68,"status":"out","pose":"walking","confidence":0.88,"source":"test","holdMs":60000}'
```

앱과 서버를 모두 껐다가 서버 먼저, 앱 나중 순서로 다시 켭니다.
